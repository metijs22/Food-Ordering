# 🍽️ فود آردرینگ (Food Ordering)

سیستم سفارش آنلاین غذا — یک وب‌اپلیکیشن فرانت‌اند کامل با HTML، CSS و JavaScript خالص (بدون فریمورک).

---

## ✨ امکانات

### 👤 کاربر
- 🍔 مشاهده لیست رستوران‌ها با جستجو
- 📋 مشاهده منوی هر رستوران
- 🛒 افزودن، حذف و تغییر تعداد اقلام در سبد خرید
- 💳 پرداخت با کارت یا پرداخت در محل
- 📦 ردیابی سفارش با تایم‌لاین زنده (آماده‌سازی ← ارسال ← تحویل)
- 📱 طراحی واکنش‌گرا (Responsive) برای موبایل و دسکتاپ

### 🔐 مدیر
- 📊 داشبورد آمار (تعداد سفارش‌ها، مجموع فروش، وضعیت‌ها)
- 📋 لیست تمام سفارش‌ها با جزئیات
- ✏️ تغییر وضعیت سفارش (آماده‌سازی / ارسال / تحویل شد)
- 🔍 جستجو بر اساس کد سفارش، نام مشتری یا شماره موبایل
- 🗑️ حذف سفارش تکی یا همه سفارش‌ها
- 👁️ مشاهده صفحه ردیابی هر سفارش

---

## 🛠️ تکنولوژی‌ها

| لایه | تکنولوژی |
|------|-----------|
| ساختار | HTML5 |
| استایل | CSS3 (RTL، Responsive) |
| منطق | Vanilla JavaScript (ES6+) |
| ذخیره‌سازی | `localStorage` مرورگر |
| فریمورک | ❌ ندارد |
| بک‌اند | ❌ ندارد (دمو فرانت‌اند) |
